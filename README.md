# سوق الجيران

تطبيق ويب وتطبيق Android مبنيان لخدمة محلات الأحياء والعملاء والموصلين في الجزائر. يعتمد المشروع على **React 19** و**Vite 7** للواجهة، وعلى **Supabase** للمصادقة والبيانات، مع طبقة خادم Node.js متاحة لبعض التكاملات المُدارة.

> يحتوي هذا المستودع على المصدر والاختبارات والترحيلات والإعدادات اللازمة للتطوير. لا يحتوي على مفاتيح إنتاج أو كلمات مرور أو رموز وصول حقيقية.

## ما الذي يتضمنه المستودع؟

| المسار | الغرض |
|---|---|
| `client/` | واجهة React/Vite، بما فيها العربية والفرنسية وخطوط الواجهة. |
| `server/` | خادم Node.js وطبقات التكامل والاختبارات. |
| `supabase/migrations/` | ترحيلات Supabase المطبقة أو الموثقة للمشروع. |
| `android/` و`capacitor.config.ts` | إعداد تغليف Android عبر Capacitor. |
| `server/*.test.ts` | اختبارات Vitest الحارسة لتدفقات التطبيق. |
| `docs/local-environment.template` | أسماء متغيرات البيئة فقط، من دون قيم حساسة. |

## المتطلبات المحلية

يلزم تثبيت **Node.js 22** أو أحدث ضمن سلسلة 22، و**pnpm**. إن أردت تشغيل وظائف Supabase الحية، تحتاج مشروع Supabase تملكه ومفاتيح Publishable الخاصة به. كما يلزم حساب Google Cloud مع مفتاح Maps مقيّد بالنطاقات المصرح بها عند اختبار الخرائط.

```bash
node --version
corepack enable
pnpm --version
```

## البدء السريع

استنسخ المستودع وثبت التبعيات باستخدام ملف القفل، ثم جهّز إعدادك المحلي. لا ترفع ملف البيئة المحلي إلى GitHub.

```bash
git clone https://github.com/Zerassam/souq-jiran.git
cd souq-jiran
pnpm install --frozen-lockfile
cp docs/local-environment.template .env.local
```

املأ فقط المتغيرات اللازمة للوظائف التي تريد تجربتها داخل `.env.local`. يبدأ التطوير بالأمر التالي:

```bash
pnpm dev
```

ثم افتح الرابط المحلي الذي يظهر في الطرفية. قد تُدار بعض قيم منصة الاستضافة في بيئة الإنتاج تلقائياً؛ لا تنسخها من إنتاج قائم ولا تنشرها في مستودع.

## التحقق قبل المساهمة

شغّل الاختبارات والبناء قبل إرسال أي تغيير:

```bash
pnpm test
pnpm build
git diff --check
```

يوفر `pnpm test` اختبارات Vitest، بينما يتحقق `pnpm build` من بناء الواجهة وحزمة الخادم. لا يُعد نجاح الاختبارات بديلاً عن تجربة حية لحسابات العميل والتاجر والموصل في بيئة آمنة.

## إعداد البيئة المحلية

تجد جميع الأسماء في `docs/local-environment.template`. الجدول التالي يوضح متى تحتاجها:

| المجموعة | المتغيرات | مطلوبة متى؟ |
|---|---|---|
| Supabase للواجهة | `VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY` | مطلوبة للمصادقة والبيانات الحية في المتصفح. |
| خرائط Google | `VITE_GOOGLE_MAPS_API_KEY` | عند تجربة الخريطة أو اختيار موقع وعنوان. |
| تحليلات الواجهة | `VITE_ANALYTICS_ENDPOINT` و`VITE_ANALYTICS_WEBSITE_ID` | اختيارية لتشغيل التحليلات في بيئتك الخاصة. |
| Supabase للخادم | `SUPABASE_URL` و`SUPABASE_KEY` | عند تشغيل إجراءات خادم تتصل بـ Supabase. لا تستخدم مفتاح `service_role` في المتصفح أبداً. |
| الجلسات والخادم | `JWT_SECRET` و`DATABASE_URL` و`OAUTH_SERVER_URL` و`VITE_OAUTH_PORTAL_URL` و`VITE_APP_ID` | عند تشغيل طبقة الخادم وتكامل OAuth خارج المنصة المُدارة. |
| إشعارات Firebase | متغيرات `VITE_FIREBASE_*` و`FIREBASE_SERVICE_ACCOUNT_JSON` | اختيارية، وفقط عند تهيئة الإشعارات فعلياً. |
| إشعارات الطلبات | `ORDER_PUSH_WEBHOOK_SECRET` و`ADMIN_PHONE_NUMBER` | مطلوبة فقط للـ webhook أو رابط التواصل الإداري المعتمد. |

> كل قيمة تبدأ بـ `VITE_` تُضمّن في حزمة المتصفح، لذلك يجب أن تكون عامة أو Publishable فقط. لا تضع كلمة مرور، أو `service_role`، أو JSON حساب خدمة Firebase، أو سر webhook في أي متغير `VITE_`.

## Supabase والترحيلات

تُحفظ الترحيلات تحت `supabase/migrations/`. راجع ملف الترحيل ودليل التشغيل المرتبط به قبل تطبيق أي تغيير على قاعدة بياناتك. لا تعِد تشغيل ترحيلات تنظيف البيانات أو ترحيلات مخصصة للإنتاج على قاعدة محلية أو جديدة من دون فهم آثارها.

تشمل مسارات التطبيق الرئيسية Email OTP، اعتماد التاجر والموصل يدوياً، عروض المتاجر المعتمدة، الإحالات، وطلبات التوصيل. يجب اختبار سياسات RLS وRPC في مشروع Supabase تملكه قبل أي نشر.

## Android عبر Capacitor

يتضمن المستودع إعداد Android. بعد تشغيل الواجهة والتحقق منها محلياً، استخدم أوامر Capacitor المعرّفة في المشروع عند الحاجة إلى مزامنة مشروع Android. يلزم Android Studio وSDK Android لإنتاج APK محلي. لا يعتبر APK debug نسخة إنتاج أو نسخة متجر.

## آلية اللغات والخطوط

العربية هي اللغة الافتراضية، والفرنسية اختيارية من زر اللغة داخل التطبيق مع حفظ التفضيل محلياً. تستخدم واجهة العربية ملفي **Majalla Regular** و**Majalla Bold** المرفقين من المالك كأصول ويب، بينما تبقى واجهة الفرنسية بخط مستقل وواجهة LTR.

## قواعد الأمان والمساهمة

لا تُضف مفاتيح أو كلمات مرور أو رموز Firebase أو JSON حسابات خدمة إلى Git. انسخ `docs/local-environment.template` محلياً إلى `.env.local` واستخدمه بقيمك الخاصة فقط. لا تنشئ مراجعات أو تقييمات أو بيانات عميل تجريبية في الواجهة. يجب أن تمر تغييرات المخطط عبر ترحيلات قابلة للمراجعة، وأن تمر تغييرات الواجهة عبر الاختبارات والبناء.

## ملاحظات حول بيئة الإنتاج

يستخدم النشر الحالي بعض خدمات الاستضافة والتكاملات المُدارة. لذلك قد لا تعمل ميزات الخادم أو OAuth أو التخزين أو التنبيهات بنفس الإعداد المحلي من دون توفير بدائلها أو إعداد متغيراتها. الواجهة وSupabase يمكن تطويرهما محلياً بعد الإعداد المناسب، أما أسرار الإنتاج فتظل في بيئة النشر فقط.

## الدعم التشغيلي

قبل فتح طلب تغيير، أرفق وصفاً قابلاً لإعادة الإنتاج، ودور الحساب المتأثر، ونتيجة `pnpm test` و`pnpm build` إن كان التغيير برمجياً. لا ترفق رموز OTP أو كلمات مرور أو مفاتيح وصول في التذاكر أو اللقطات.
