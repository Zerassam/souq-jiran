# جاهزية اختبار أول حساب هاتفي

تم فتح معاينة سوق الجيران في:

`https://3000-i3197jyeazyssqhiaw41i-2adb3ce6.us4.manus.computer/?from_webdev=1`

وتظهر بوابات إنشاء الحساب الثلاث بوضوح: التاجر، الموصل، والزبون. بوابة الزبون تعرض إجراء **«دخول أو إنشاء حساب»**، بينما بوابتا التاجر والموصل تعرضان إجراءات التسجيل المتخصصة.

## الإجراء عند إنشاء أول مستخدم برقم الهاتف

1. يختار المستخدم بوابته ويكمل التسجيل برقم هاتف جزائري.
2. بعد نجاح Firebase SMS يظهر المستخدم في **Firebase Authentication → Users** ويصبح له Firebase UID.
3. يُشغّل المالك السكربت الإداري الموثق في [`firebase-custom-claims-guide.md`](./firebase-custom-claims-guide.md) على ذلك الـUID لتعيين `role: "authenticated"`.
4. يسجّل المستخدم الخروج ثم الدخول مجدداً لتجديد Firebase ID token.
5. يختبر المستخدم مسار تغيير رقم الهاتف؛ يجب أن ينجح فقط عند تطابق رقم Firebase الموثق مع التحدي المرتبط بحساب Supabase.

لا يُنشأ UID أو يُرسل SMS من طرف الاختبار الآلي، لأن ذلك يتطلب رقم هاتف حقيقياً وموافقة صاحبه.
