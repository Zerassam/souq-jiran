شروط الخدمة طلب حذف الحساب

ملخص واضح

نستخدم بياناتك لتشغيل حسابك وطلباتك والتواصل المرتبط بالخدمة وتأمينها. لا نبيع بياناتك الشخصية. يمكنك طلب الوصول إلى بياناتك أو تصحيحها أو حذف حسابك وفق ما تسمح به الالتزامات التشغيلية والقانونية.

1. نطاق هذه السياسة

تنطبق هذه السياسة على تطبيق وموقع «سوق الجيران» وخدماته المرتبطة. تشرح كيفية جمع البيانات الشخصية واستخدامها وحمايتها عند التسجيل، تصفح المحلات، إنشاء الطلبات، واستخدام ميزات الموقع أو الإشعارات عند منح الإذن.

2. البيانات التي قد نجمعها

  • بيانات الحساب: الاسم، البريد الإلكتروني، رقم الهاتف، نوع الحساب، وبيانات الملف الشخصي التي تدخلها.
  • بيانات النشاط والطلب: بيانات المحل أو نطاق التوصيل أو العنوان ومحتوى الطلب والحالة والتواصل المرتبط به.
  • بيانات الموقع: موقع تقريبي أو دقيق فقط عند منح إذن الموقع، لاستخدام ميزات البحث والتوصيل ذات الصلة.
  • بيانات الجهاز والإشعارات: رمز إشعارات Firebase Cloud Messaging وإعدادات الإشعار ومعلومات تقنية محدودة لازمة لتشغيل الخدمة ومنع إساءة الاستخدام.
  • بيانات الدعم: أي معلومات ترسلها إلينا عند طلب المساعدة أو حذف الحساب.

3. كيف نستخدم البيانات

نستخدم البيانات لإنشاء الحسابات والتحقق منها، تشغيل الطلبات والتوصيل، إظهار النتائج ذات الصلة بالموقع عند تفعيل الإذن، إرسال الإشعارات المرتبطة بتغير حالة الطلب، تقديم الدعم، وحماية المنصة ومنع الاحتيال أو الاستخدام المخالف. لا نستخدم رقم هاتفك أو رمز جهازك لأغراض إعلانية من أطراف خارجية.

4. مزودو الخدمات

نعتمد على Supabase لتخزين بيانات التطبيق والمصادقة المرتبطة بها، وعلى Firebase Authentication للتحقق من رقم الهاتف وFirebase Cloud Messaging لإرسال الإشعارات عند تفعيلها. قد تعالج هذه الخدمات البيانات وفق سياساتها الخاصة وبنية الاستضافة التابعة لها. نستخدم خرائط OpenStreetMap/Leaflet لعرض الخريطة، وقد تتلقى الجهة المزودة لطبقات الخريطة عنوان الشبكة اللازم لعرضها.

5. مشاركة البيانات

نشارك الحد الأدنى اللازم من البيانات داخل الأطراف المعنية بالطلب لتشغيله، مثل بيانات الاتصال أو العنوان أو حالة الطلب بحسب الدور. قد نفصح عن البيانات لمزودي الخدمة المذكورين أعلاه أو إذا تطلب قانون واجب التطبيق ذلك أو لحماية الحقوق والسلامة. لا نبيع البيانات الشخصية ولا نؤجرها.

6. الأذونات والاختيارات

يمكنك رفض أو سحب إذن الموقع والإشعارات من إعدادات جهازك. قد يؤدي ذلك إلى عدم عمل الميزات المعتمدة عليهما، مثل اقتراح المحلات القريبة أو التنبيهات الفورية لحالة الطلب. ويمكنك تعديل البيانات المتاحة داخل حسابك أو طلب المساعدة عند تعذر ذلك.

7. الحماية والاحتفاظ

نطبق تدابير تقنية وتنظيمية معقولة، مثل ضوابط الوصول والاتصال الآمن، لحماية البيانات. لا توجد وسيلة نقل أو تخزين آمنة بنسبة مطلقة. نحتفظ بالبيانات ما دامت ضرورية لتقديم الخدمة أو معالجة النزاعات أو الامتثال للالتزامات القانونية، ثم نحذفها أو نزيل إمكانية ربطها بالشخص عندما يكون ذلك مناسباً.

8. حقوقك وطلباتك

يمكنك طلب الاطلاع على بياناتك أو تصحيحها أو حذف حسابك، وسنتحقق من الهوية قبل تنفيذ الطلب. قد تبقى سجلات محدودة للطلبات المكتملة أو النزاعات أو الالتزامات القانونية للمدة اللازمة. لبدء طلب الحذف، استخدم صفحة طلب حذف الحساب.

9. النقل الدولي والأطفال

قد تتضمن البنية التحتية لمزودي الخدمات معالجة بيانات خارج بلد إقامتك. إذا كان المستخدم دون سن الرشد وفق القانون الواجب التطبيق، فيجب عليه استخدام الخدمة بموافقة وإشراف وليه أو ممثله القانوني.
