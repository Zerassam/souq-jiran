# مرجع زر الرجوع في Android

تمت مراجعة وثائق Capacitor الرسمية لمكوّن `@capacitor/app` بتاريخ 2026-08-26:

- المصدر: <https://capacitorjs.com/docs/apis/app>
- تثبيت المكوّن يتطلب مزامنة Capacitor بعد الإضافة.
- المستمع `App.addListener('backButton', ...)` خاص بـ Android، ويعطّل السلوك الافتراضي للزر عند تسجيله.
- تعرض الحمولة `canGoBack` لمعرفة وجود سجل متصفح قابل للرجوع.
- عند اكتمال أي تنقل منطقي، يمكن استدعاء `window.history.back()`؛ وعند الخروج المتعمد فقط يمكن استدعاء `App.exitApp()`.

يعتمد التطبيق سياسة محلية: إغلاق الطبقة/النافذة المفتوحة أولاً، ثم العودة إلى واجهة العميل، ثم الاستفادة من سجل المتصفح إن وُجد. لا يستدعي التطبيق الخروج القسري عند وجود صفحة فرعية أو نافذة مفتوحة.
