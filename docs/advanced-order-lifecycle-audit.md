# تدقيق توسعة دورة الطلب — سوق الجيران

## الحالة قبل التوسعة

يوفر التطبيق حساب عميل وتخزين رقم هاتف اختياري في الملف الشخصي، ويدعم اختيار الولاية والبلدية، ويخزن عنوان التسليم كبيانات JSON مع الطلب. يوجد كذلك اختيار مرئي لموضع على خريطة مبسطة داخل الواجهة. إلا أن هذا الموضع لا يمثل إحداثيات GPS فعلية، ولا يوجد تحقق من رقم الهاتف أو نظام بلاغ/حظر للعملاء.

| المجال | الوضع القائم | الفجوة التي ستعالج |
|---|---|---|
| جدية العميل | حساب عميل ورقم هاتف غير موثق | تحقق OTP، سياسة إلزامية للطلبات الكبيرة أو بين الولايات، وتقارير وحظر خاضع للمشرف |
| العنوان | ولاية وبلدية وعنوان JSON واختيار موضع مبسط | إحداثيات دقيقة، موافقة صريحة على الموقع، ووصف عنوان قابل للمراجعة |
| النطاق الجغرافي | تصفية المحلات حسب الولاية/البلدية؛ تغطية الموصل ضمن ولاية واحدة | اختيار متجر من منطقة أخرى، تحديد وجهة مستقلة، ومسافة ورسوم وزمن تقديري |
| السعر | رسوم يرسلها العميل إلى إنشاء الطلب | حساب خادمي لا يثق بالعميل وفق مسافة ومعامل وزن قابل للضبط |
| دورة الطلب | `pending → accepted → preparing → ready → assigned → delivered` | إثباتات مرحلية لتسليم التاجر للموصل، استلام العميل، وتحويل وتأكيد المستحقات |
| المساءلة | رسائل وأرشفة وإشعارات إدارية | سجل أحداث غير قابل للتعديل، وتقارير سلوك العميل، وقرارات الحظر |

## ضوابط التنفيذ

ستبقى المبالغ المسجلة **قيماً محاسبية لحالة الطلب** وليست محفظة أو خدمة احتجاز مالي. لن ينفذ التطبيق تحويل أموال أو يحتفظ بوسيلة دفع. ستسجل كل خطوة تأكيد من صاحب الصلاحية المناسبة، مع حفظ الطابع الزمني والجهة المنفذة في سجل أحداث الطلب.

> لا يرسل التطبيق رمز تحقق حقيقياً أو يجري مكالمة تلقائية قبل تهيئة مزود رسائل/اتصالات خارجي واعتماد بياناته. إلى حين ذلك، يمكن تجهيز تدفق التحقق والواجهة، لكن لا يجوز ادعاء وصول OTP فعلياً.
