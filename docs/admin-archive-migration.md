# تفعيل أرشيف الإدارة والحذف الشخصي

قبل استعمال أزرار الحذف الجديدة، افتح مشروع **Supabase** ثم اذهب إلى **SQL Editor** وشغّل محتوى الملف:

```text
supabase/migrations/20260817_admin_archives.sql
```

ينشئ الترحيل سجلي أرشفة مستقلين للطلبات والرسائل. عند ضغط التاجر أو الموصل على «حذف من قائمتي»، تسجل قاعدة البيانات صفاً له بقيمة `deleted_by_user = true` بدلاً من حذف الطلب أو الرسالة الأصلية. لذلك تبقى البيانات ظاهرة كاملة للمشرف في الأرشيف الإداري، ويقتصر الحذف الفعلي على الدالتين المحميتين بدور `admin`.

بعد التنفيذ، سجّل الخروج ثم ادخل مجدداً لاختبار سياسات RLS في جلسة جديدة. لا تُشغّل الحذف النهائي إلا من لوحة المشرف وبعد مراجعة السجل، فهو يحذف الطلب مع عناصره ورسائله المرتبطة ولا يمكن التراجع عنه.
