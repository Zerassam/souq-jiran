# تحقق الواجهة: بوابة إنشاء حساب الزبون

في المعاينة المحلية، فُتحت بوابة **«حساب الزبون»** ثم تبويب **«حساب جديد»** بنجاح.

النموذج يعرض العناصر التالية قبل أي إرسال خارجي:

| العنصر | النتيجة |
|---|---|
| عنوان الحساب | «حساب العميل» |
| حقل الهوية | «رقم الهاتف أو البريد الإلكتروني» |
| حقل الحماية | «كلمة المرور» |
| إجراء المتابعة | «إنشاء حساب» |
| رسالة التوضيح | «يمكنك المتابعة برقم الهاتف أو البريد لإرسال الطلبات ومتابعتها بأمان.» |

هذا يؤكد صحة وصول المستخدم إلى نموذج الحساب من البوابة المستقلة. لم يُدخل رقم هاتف ولم يُضغط زر إنشاء الحساب، لذلك لم تُرسل رسالة SMS ولم يُنشأ Firebase UID في هذا التحقق.
