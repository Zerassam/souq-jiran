# تحقق حسابات العرض ولوحات الأدوار

**تاريخ التحقق:** 18 أغسطس 2026  
**النطاق:** حساب عرض للتاجر وحساب عرض للموصل في بيئة معاينة التطبيق.

## إصلاح تسجيل الموصل

عولجت حالة سباق قصيرة بين إنشاء صف `profiles` وتجهيز مطالبات جلسة Supabase الجديدة. عند رفض الإدراج الأول لملف الموصل بخطأ الصلاحية `42501`، يجدد التطبيق الجلسة مرة واحدة فقط ثم يعيد محاولة إدراج السجل نفسه. لا يعاد إنشاء حساب المصادقة، ولا تتكرر المحاولات في حالات أخطاء أخرى. بعد النجاح تُطبّق الجلسة المجددة وتُفتح لوحة الموصل.

| عنصر التحقق | النتيجة |
|---|---|
| التسجيل عبر نموذج الموصل | ناجح |
| إنشاء سجل `couriers` | ناجح بعد آلية إعادة المحاولة المحكومة عند الحاجة |
| التوفر المسجل | صباحاً |
| نطاق التغطية المسجل | البليدة |
| حالة الحساب | بانتظار موافقة المشرف |
| اختبار الانحدار | اختبار Vitest ثابت يغطي مسار `42501` وتجديد الجلسة وإعادة الإدراج |

## التحقق المرئي من لوحة التاجر

تم الدخول بحساب عرض تاجر وفتح لوحة إدارة المحل. ظهرت واجهة المحل وحالة الحساب، وعدّاد الطلبات الجديدة، والرابط المباشر لقائمة الطلبات، فضلاً عن مسارات إدارة المنتجات والطلبات وإعدادات التوصيل والرسائل. لم يظهر خطأ وقت تشغيل أثناء فتح اللوحة.

| العنصر المرئي | النتيجة |
|---|---|
| فتح لوحة المحل | ناجح |
| عدّاد الطلبات الجديدة | ظاهر |
| إدارة الطلبات والمنتجات | ظاهرة |
| إعدادات التوصيل والرسائل | ظاهرة |

## التحقق المرئي من لوحة الموصل

تم تسجيل الخروج ثم تسجيل الدخول مجدداً بحساب عرض الموصل للتأكد من أن بيانات الدخول مستقلة عن جلسة التسجيل. فتحت اللوحة بصورة سليمة وأظهرت حالة المراجعة، نوع المركبة، نطاق البليدة، وقت العمل الصباحي، ومرشح الحالة، وتبويبات الطلبات المتاحة والنشطة وسجل التسليمات وساعات العمل والرسائل.

> عدم ظهور طلبات قابلة للاستلام قبل اعتماد الموصل هو السلوك المقصود؛ تُتاح الطلبات بعد موافقة المشرف على حسابه.

| العنصر المرئي | النتيجة |
|---|---|
| فتح لوحة الموصل | ناجح |
| شارة انتظار الموافقة | ظاهرة |
| وقت العمل ونطاق التغطية | ظاهران |
| مرشح حالة الطلبات | ظاهر |
| تبويبات الطلبات والسجل والدوام والرسائل | ظاهرة |

## الخصوصية

لا تتضمن هذه الوثيقة عناوين البريد أو كلمات المرور الخاصة بحسابات العرض. تُسلَّم بيانات الدخول مباشرةً لصاحب المشروع فقط، ولا تُحفظ في المستودع.
